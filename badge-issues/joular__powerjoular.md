# Add the Green Software Landscape badge to the README

**Repo:** [joular/powerjoular](https://github.com/joular/powerjoular) · **Landscape entry:** PowerJoular · **Sub-category:** Device Measurement

Hi! PowerJoular is listed in the [Green Software Landscape](https://landscape.bundesverband-green-software.de), a directory of relevant Green Software tools categorized into a landscape. It is run by the [Bundesverband Green Software](https://www.bundesverband-green-software.de/), a German NGO with currently over 30 member companies. The landscape itself is open source: [bundesverband-green-software/landscape](https://github.com/bundesverband-green-software/landscape).

We recently started to provide badges, one per sub-category of the landscape. PowerJoular would fit **Device Measurement**. It was added to the landscape in [landscape#33](https://github.com/bundesverband-green-software/landscape/pull/33).

[![Green Software Landscape: Device Measurement](https://raw.githubusercontent.com/bundesverband-green-software/landscape/refs/heads/main/badges/device-measurement.svg)](https://landscape.bundesverband-green-software.de)
