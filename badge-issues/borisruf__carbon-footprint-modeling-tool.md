Hi! Carbon Footprint Modeling Tool is listed in the [Green Software Landscape](https://landscape.bundesverband-green-software.de), a directory of relevant Green Software tools categorized into a landscape. It is run by the [Bundesverband Green Software](https://www.bundesverband-green-software.de/), a German NGO with currently over 30 member companies. The landscape itself is open source: [bundesverband-green-software/landscape](https://github.com/bundesverband-green-software/landscape).

We recently started to provide badges, one per sub-category of the landscape. Carbon Footprint Modeling Tool would fit **Modeling**. It was added to the landscape in [landscape#15](https://github.com/bundesverband-green-software/landscape/pull/15).

[![Green Software Landscape: Modeling](https://raw.githubusercontent.com/bundesverband-green-software/landscape/refs/heads/main/badges/modeling.svg)](https://landscape.bundesverband-green-software.de)
