# Add the Green Software Landscape badge to the README

Hi! CEEMS is listed in the [Green Software Landscape](https://landscape.bundesverband-green-software.de), a directory of relevant Green Software tools categorized into a landscape. It is run by the [Bundesverband Green Software](https://www.bundesverband-green-software.de/), a German NGO with currently over 30 member companies. The landscape itself is open source: [bundesverband-green-software/landscape](https://github.com/bundesverband-green-software/landscape).

We recently started to provide badges, one per sub-category of the landscape. CEEMS would fit **Bare-Metal & Host Level**. It is also listed under **Kubernetes** and **Monitoring & Tracing**, so other badges may fit as well.

[![Green Software Landscape: Bare-Metal & Host Level](https://raw.githubusercontent.com/bundesverband-green-software/landscape/refs/heads/main/badges/bare-metal-host-level.svg)](https://landscape.bundesverband-green-software.de)
