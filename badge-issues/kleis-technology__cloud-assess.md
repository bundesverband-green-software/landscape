# Add the Green Software Landscape badge to the README

**Repo:** [kleis-technology/cloud-assess](https://github.com/kleis-technology/cloud-assess) · **Landscape entry:** Cloud Assess · **Sub-category:** Public Cloud

Hi! Cloud Assess is listed in the [Green Software Landscape](https://landscape.bundesverband-green-software.de), a directory of relevant Green Software tools categorized into a landscape. It is run by the [Bundesverband Green Software](https://www.bundesverband-green-software.de/), a German NGO with currently over 30 member companies. The landscape itself is open source: [bundesverband-green-software/landscape](https://github.com/bundesverband-green-software/landscape).

We recently started to provide badges, one per sub-category of the landscape. Cloud Assess would fit **Public Cloud**.

[![Green Software Landscape: Public Cloud](https://raw.githubusercontent.com/bundesverband-green-software/landscape/refs/heads/main/badges/public-cloud.svg)](https://landscape.bundesverband-green-software.de)
