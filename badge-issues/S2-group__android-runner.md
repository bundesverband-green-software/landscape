# Add the Green Software Landscape badge to the README

Hi! Android Runner is listed in the [Green Software Landscape](https://landscape.bundesverband-green-software.de), a directory of relevant Green Software tools categorized into a landscape. It is run by the [Bundesverband Green Software](https://www.bundesverband-green-software.de/), a German NGO with currently over 30 member companies. The landscape itself is open source: [bundesverband-green-software/landscape](https://github.com/bundesverband-green-software/landscape).

We recently started to provide badges, one per sub-category of the landscape. Android Runner would fit **Mobile Application**.

[![Green Software Landscape: Mobile Application](https://raw.githubusercontent.com/bundesverband-green-software/landscape/refs/heads/main/badges/mobile-application.svg)](https://landscape.bundesverband-green-software.de)
